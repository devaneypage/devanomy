Zettelkasten Note-Taking

Each note receives a unique identifier and supports bidirectional linking to foster emergent insights and complex thinking.

ID Format:

AC.ID-YYYYMMDD-Seq[/Branch]

Example:

20.03-20241209-001

Philosophy reading note, contemporary philosophy, created Dec 9, 2024

Link Symbols:

→ References / Links Forward

← Cited By / Links Back

↔ Mutual / Bidirectional
